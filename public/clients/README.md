# Customer logos

Permission-cleared client logos for the homepage "trusted by" bar. Each file
here must match the `logo` path referenced in `src/data/trust.ts` (`CLIENTS`):

- de-bijenkorf.png
- picnic.png
- bidfood.webp
- asa-matcha.png
- noor.png

To swap a logo, drop the new file in and update its path in `CLIENTS` if the
extension changes. Prefer transparent PNG/WEBP/SVG, trimmed of padding. The bar
renders every entry that has a file.
